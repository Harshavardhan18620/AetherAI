## 📦 Local Development

To run the application locally without build tools:

```bash
# Clone the repository
git clone https://github.com/Harshavardhan18620/AetherAI.git

# Navigate into the project directory
cd AetherAI

# Open directly in your browser or run a lightweight server:
npx serve .
# or with Python:
python -m http.server 8000
```

Visit `http://localhost:8000` to interact with the platform.

## 🚢 Deployment Guide

### Deploying to GitHub Pages
1. Go to repository **Settings** > **Pages**.
2. Under **Build and deployment** > **Branch**, select `main` (or `gh-pages`) and `/ (root)`.
3. Click **Save**. Your site will be published at `https://harshavardhan18620.github.io/AetherAI/`.

### Deploying to Vercel
```bash
npx vercel
```
*`vercel.json` is pre-configured with clean URLs.*
